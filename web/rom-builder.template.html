Which ROM sets and files do I need?

These recipes match the 19 sets configured in this core, including Budweiser Tapper (840127), Two Tigers (Tron Conversion), Rampage (Rev 3), Max RPM (v2), and the MCR-3 Mono version of Demolition Derby. Other revisions may have different ROM checksums.

The builder matches file contents by CRC, so renamed files and merged ZIPs work. Add missing parent ZIPs if needed. Missing chips are listed beside each game. Corrupt or unsupported ZIP files are rejected.

The sound timing file ssio.prom is required in cores/alanswx.MCR/. Keep the one from your core installation, or drop your own verified 32-byte file here. Some ROM sets contain the matching timing PROM; the builder can find it there too.

The SD-card ZIP contains verified games under roms/MCR/, and the sound PROM if supplied. Extract it at the SD-card root. Install the core separately, then select any game ROM when launching it. The core identifies the game automatically.

Individual downloads go in roms/MCR/. Environmental Discs of Tron needs core version 0.6.0 or later. Journey’s separate music sample is not included. No copyrighted ROM data is included with this page.
